SMART ATTENDANCE - VS CODE VERSION

This is a clean standalone recreation inspired by the public Smart Attendance page you provided. It does not contain the original Bolt source code.

RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html using Live Server, OR run any local HTTP server.
4. Chrome/Edge -> allow camera permission on Live Camera.

LOGIN:
Any non-empty username and password works for this demo.

FUNCTIONS:
- Login
- Dashboard
- Student registration
- Student archive/restore
- System/default camera
- Camera capture
- Attendance marking
- Present/Late
- Duplicate prevention per day
- Attendance history
- Reports
- CSV export
- Settings page
- Browser localStorage persistence

NOTE:
This is an academic/demo frontend. Camera capture is not a validated face-recognition/liveness system. For production, use a secure backend and validated biometric/liveness solution with appropriate consent and security.
